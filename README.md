# MindShield AI - Detect Before you React

MindShield is an AI-powered mental health and safety platform specially designed to **detect psychological manipulation** in digital media that provide users with a secure, supportive, and intelligent digital environment. The project focuses on improving user well-being through smart monitoring, personalized recommendations, and accessible resources.

## Features

* **Core focus** - Detecting psychologically manipulative tactics and patterns and bring it to the user's knowledge. Not just to say spam/fake or real.
* **AI-Based Risk Detection** – Detects patterns or behaviors that may indicate mental distress or unsafe situations.
* **Personalized Recommendations** – Give a clear explanation on why it is flagged as a spam or psychologically manipulative. Suggests relevant coping strategies, resources, or actions based on user needs.
* **User-Friendly Dashboard** – Clean and simple interface for easy navigation and insights.
* **Data Privacy & Security** – Ensures user data is handled securely with privacy-first practices.
* **Real-Time Alerts** – Sends notifications or warnings when risk factors are identified.

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python / Django
* **AI/ML:** Python libraries for analytics and prediction, Llama3 as LLM

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/mindshield.git
```

2. Navigate to the project folder:

```bash
cd mindshield
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

## Usage

* Open the application in your browser.
* Explore dashboard insights and recommendations.
